How to name alkenes and alkynes (with the locant rules)

Alkenes and alkynes are named like alkanes with one non-negotiable extra rule: the parent chain must contain the double or triple bond, even when a longer chain is available without it. Get that rule fixed first, then the numbering and locant placement fall into place.

What is the difference between an alkene and an alkyne?

An alkene contains at least one carbon-carbon double bond, an alkyne contains at least one carbon-carbon triple bond, and both are described as unsaturated because they carry fewer hydrogens than the equivalent alkane. Ethene, CH2=CH2, is the simplest alkene; ethyne, CH≡CH, is the simplest alkyne. Everything about naming an alkane still applies here — longest chain, lowest locants, alphabetised substituents — but the presence of the multiple bond adds one overriding rule and one small spelling change (-ene or -yne in place of -ane).

How do you name an alkene?

Name it like an alkane, except the parent chain must contain the double bond and the ending changes from -ane to -ene. In full:

  1. Find the longest chain that contains the double bond. This is the single most-missed rule in the whole topic. If a longer chain exists but skips over the double bond, it is not eligible to be the parent — the chain you pick must run through both carbons of the double bond, even if that means settling for a chain that is one or two carbons shorter than the longest one available.
  2. Number the chain to give the double bond the lowest locant. This comes before considering any substituents at all.
  3. Identify and alphabetise the substituents, exactly as for an alkane.
  4. Assemble the name, replacing -ane with -ene and placing the double bond's locant directly before it.

Where does the number go — but-2-ene or 2-butene?

Modern IUPAC practice puts the locant immediately before the suffix it belongs to, giving but-2-ene; the older style, 2-butene, places every locant at the front and is still seen in some textbooks and exam specifications. Both names describe the same molecule, and both are understood everywhere, but current IUPAC recommendations (and this tool) use the modern form: the locant sits right next to the part of the name it locates, which matters once a molecule has more than one kind of locant to keep track of (a double bond and a substituent, say). Expect to meet both forms in coursework — but write the modern one when asked for the preferred IUPAC name.

How do you number the chain in an alkene?

Number the chain to give the double bond the lowest possible locant, and that rule overrides giving the substituents the lowest locants. In hex-1-ene, for instance, the double bond is fixed at carbon 1 no matter what else is attached further along the chain — you would never renumber from the other end just to lower a substituent's locant. Only once the double bond's position is settled do you look at the substituents, and only if there is still a genuine choice left (for example, a symmetric chain where the double bond locant is the same from either end) do the substituent locants get to break the tie.

What about two double bonds?

Two double bonds are named with the suffix -diene, and the linking vowel a is kept before a consonant so the name stays pronounceable, as in penta-1,3-diene. The rule behind that spelling: the stem's final -a is normally dropped before a suffix starting with a vowel (pent- + -ene gives pent-1-ene), but it is kept when the suffix starts with a consonant, since "pent-1,3-diene" would be awkward to say. Numbering still follows the lowest-locant rule for the double bonds as a set: for CH2=CH-CH=CH-CH3, numbering from the left gives the bonds locants {1, 3}, while numbering from the right gives {2, 4} — {1, 3} is lower at the first point of difference, so penta-1,3-diene is correct.

How do you name an alkyne?

A carbon-carbon triple bond is named with the suffix -yne in exactly the same pattern as -ene, so hex-3-yne is a six-carbon chain with the triple bond starting at carbon 3. Every rule above for alkenes — the chain must contain the multiple bond, the multiple bond gets the lowest locant, the locant sits directly before the suffix — applies identically to alkynes. The only difference is the ending and the fact that a triple bond uses two fewer hydrogens than the equivalent double bond at the same position.

What if a molecule has both a double and a triple bond?

The name combines both suffixes as -en-yne, with the double bond's locant before -en and the triple bond's locant before -yne, and the chain is numbered to give the lower locant set overall, treating both multiple bonds together rather than picking one to prioritise. If the two possible numberings are genuinely tied on that combined set, the double bond takes the lower of the two available numbers and the triple bond takes the higher one — the double bond wins ties over the triple bond.

Do you need E/Z here?

Not for this tool: geometric (E/Z) isomerism is a real and separate part of alkene nomenclature, but it describes the three-dimensional arrangement of groups around a double bond, and that is not something a 2-D skeletal structure captures. This tool names the connectivity of the molecule you draw; it does not ask, or answer, whether a particular double bond is E or Z, so you will not see an E/Z descriptor in any name it returns.

Worked example: 4-methylpent-2-ene

Take the chain CH3-CH=CH-CH(CH3)-CH3. There are five carbons in the main chain, so the parent is pentene, and there is one methyl branch on the fourth carbon of that chain (counting from the left).

Number from the left: the double bond falls between carbons 2 and 3, so its locant is 2, and the methyl branch is on carbon 4. Number from the right instead: the double bond now falls between carbons 3 and 4, so its locant is 3 — worse than 2 — even though the methyl branch would land on carbon 2, a lower number than 4. The double bond's locant takes priority regardless, so numbering from the left is correct. Putting it together: 4-methylpent-2-ene. This is exactly the trade-off from the numbering rule above: a lower substituent locant does not get to override a higher double-bond locant.

Common mistakes when naming alkenes and alkynes

  • Picking the longest chain in the molecule instead of the longest chain that contains the double or triple bond.
  • Numbering to favour a substituent's locant instead of the double or triple bond's.
  • Writing the older locant style (2-butene) when a modern IUPAC name (but-2-ene) is asked for, or mixing the two within one name.
  • Dropping the linking "a" before a consonant-starting suffix, writing "pent-1,3-diene" instead of penta-1,3-diene.
  • Forgetting that a ring can carry a double bond too (cyclohexene, for example) — those follow a related but separate set of rules that this tool does not currently name.
