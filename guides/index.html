IUPAC naming guides

Step-by-step guides to naming organic molecules the IUPAC way — starting from a plain alkane and working up to branched chains and competing functional groups. Every rule described here can be checked against a real structure in the free namer, so you never have to take a rule on trust. For more on how the tool itself is built, see the about page.

Between them, the four guides below cover the core of IUPAC substitutive nomenclature for everyday organic molecules: naming straight and branched carbon chains, placing double and triple bonds, and deciding which functional group takes over the name when more than one is present. Each one works through several fully worked examples rather than just stating the rule, and links back to the namer so you can draw the same molecule and see the same name come out.

  • How to name alkanes Straight-chain basics: root names, counting carbons, and the -ane ending.
  • Naming alkenes and alkynes Locating double and triple bonds and giving them the lowest locant.
  • IUPAC rules for branched chains Picking the parent chain, numbering it, and ordering substituents.
  • Functional group priority Which group becomes the suffix when a molecule has more than one.

Where should I start?

Start with alkanes: the other three guides all assume you can already name a straight carbon chain before they build branches, double bonds and functional groups on top of it. Once alkanes feel routine, alkenes and alkynes, branched chains and functional group priority can be read in any order.

Already comfortable with the basics and only after one specific rule — how a tie in chain length gets broken, or which functional group outranks another — jump straight to the relevant guide from the list above; each one stands on its own once the alkane fundamentals are in place.
