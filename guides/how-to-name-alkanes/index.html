How to name alkanes (IUPAC rules, step by step)

Naming an alkane is a five-step routine: find the longest carbon chain, number it to give the lowest locants, name the branches, alphabetise them, and assemble the result. Get comfortable with those five steps and every alkane, however tangled it looks on the page, names itself the same way.

What is an alkane?

An alkane is a hydrocarbon whose carbon atoms are joined only by single bonds, so every carbon carries as much hydrogen as it can hold. Chemists call this saturated: there is no room left for a double or triple bond, and no room for another substituent without removing a hydrogen first. The general formula is CnH2n+2, where n is the number of carbons in the molecule. An alkane can be a plain straight chain, such as CH3CH2CH2CH3 (butane), or it can carry branches off that chain, such as CH3CH(CH3)CH2CH3 (2-methylbutane). This guide covers chains from one to ten carbons, the range the namer tool below can handle; branches on branches are not modelled and rarely come up at this level anyway.

What are the IUPAC steps for naming an alkane?

There are five steps: find the longest chain, number it for the lowest locants, identify the substituents, alphabetise them, and assemble the name with the correct punctuation. In full:

  1. Find the longest chain. Trace every continuous path of carbon atoms and count them; the longest gives the root name (methane, ethane, propane, and so on).
  2. Number the chain from the end that gives the lowest locants. Try both ends and keep whichever set of substituent positions is lower.
  3. Identify every substituent. Anything hanging off the parent chain is a branch, named as an alkyl group with its own locant.
  4. Order the substituents alphabetically, comparing the substituent names themselves and ignoring any di-, tri-, or tetra- prefix.
  5. Assemble the name. Commas separate numbers from each other; hyphens separate numbers from letters; the parent chain name comes last.

How do you pick the longest chain when it bends?

The longest chain is whichever continuous path has the most carbons, and that path is not always the one drawn as a straight horizontal line. This is the classic trap: a structure is often drawn with a long horizontal run and a short branch off it, and it is tempting to name the horizontal run the parent and the branch a substituent.

Take a molecule drawn as a four-carbon horizontal run with a two-carbon branch hanging off the second carbon. Read only the horizontal line and you would call it a butane with an ethyl branch, giving the name "3-ethylbutane". But trace the longest unbroken path instead: start at the far end of the branch, cross into the horizontal run through the second carbon, and continue to the far end of that run. That path is five carbons long, one more than the horizontal run alone, so the parent chain is pentane, not butane. The correct name is 3-methylpentane. Whenever a branch meets the main chain, check whether going into the branch and back out gives a longer path than staying on the line you were originally following.

How do you number the chain?

Number from whichever end gives the substituents the lowest set of locants, comparing the two possible numberings term by term at the first point where they differ. This is the first-point-of-difference rule. Suppose numbering from one end gives substituent locants {2, 3, 5} and numbering from the other end gives {2, 4, 5}. Both sets have the same number of terms and the same first number, so compare the second: 3 is lower than 4, so {2, 3, 5} wins even though the two sets are otherwise identical. It does not matter that the highest number in each set is the same (5); the decision is made at the first place the two sets disagree.

How do you name the branches?

Each branch is named as an alkyl group — methyl, ethyl, propyl, butyl, and so on — with di-, tri-, and tetra- added for two, three, or four identical branches, using the same stems as the parent chains above but with -yl in place of -ane. Repeated locants are grouped with commas (2,2-dimethyl-, not 2-methyl-2-methyl-), and the multiplying prefix is not itself alphabetised: "ethyl" is alphabetised as it stands, but "dimethyl" is alphabetised as "methyl", so ethyl comes before dimethyl even though d comes before e.

Worked example: 2,3-dimethylpentane

Take the branched chain CH3CH(CH3)CH(CH3)CH2CH3. The longest chain runs five carbons, so the parent is pentane, and there are two methyl branches, one on each of the two middle-ish carbons.

Number from the left: the methyls fall on carbons 2 and 3, giving the locant set {2, 3}. Number from the right instead: the same two carbons become carbons 4 and 3, giving {3, 4}. Compare the two sets at the first point of difference: 2 is lower than 3, so numbering from the left wins. The substituents are cited as 2,3-dimethyl, giving the full name 2,3-dimethylpentane. Numbering from the wrong end would have produced "3,4-dimethylpentane" — a name for the same molecule, but not the preferred IUPAC name, because {3, 4} loses to {2, 3} on the lowest-locant rule.

Worked example: 4-ethyl-2,2-dimethylhexane

Take the chain CH3C(CH3)2CH2CH(CH2CH3)CH2CH3. The longest chain runs six carbons, so the parent is hexane. Carbon 2 carries two methyl branches (both attached to the same carbon), and carbon 4 carries one ethyl branch.

Numbering from this end gives the locant set {2, 2, 4}. Numbering from the other end instead turns carbon 2 into carbon 5 and carbon 4 into carbon 3, giving {3, 5, 5} — worse at the very first term, since 2 is lower than 3. The original numbering stands. For the substituent order, compare "ethyl" against "methyl" (the multiplying prefix "di-" is ignored for alphabetising): e comes before m, so ethyl is cited first. The two identical methyl locants are joined with a comma. Putting it together: 4-ethyl-2,2-dimethylhexane.

Common mistakes when naming alkanes

  • Naming the chain drawn horizontally instead of tracing every path to find the true longest one.
  • Numbering from the end that "looks right" rather than the end that actually produces the lowest locant set.
  • Alphabetising by the multiplying prefix (treating "dimethyl" as starting with d), rather than by the substituent name it modifies.
  • Mixing up commas and hyphens: commas separate numbers from other numbers (2,3-dimethyl-), hyphens separate numbers from letters (2,3-dimethylpentane).
  • Trying to name a branch that itself has a branch attached to it. It happens in real molecules, but it needs nested brackets that go beyond what this tool models.
